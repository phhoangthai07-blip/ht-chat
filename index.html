Hướng dẫn Đưa lên GitHub & Kết nối Backend Thực tế

Giải thích về GitHub Pages & Backend:

GitHub Pages chỉ lưu trữ và chạy code Frontend (HTML/CSS/JS) hoàn toàn miễn phí. Để lưu dữ liệu tài khoản, mật khẩu bảo mật và tin nhắn Realtime thực sự giữa các thiết bị khác nhau, bạn cần kết nối ứng dụng với một Backend/Database Cloud như Supabase hoặc Firebase.

Bước 1: Đưa Code Lên GitHub & Deploy GitHub Pages

  1. Tạo một Repository mới trên GitHub (Ví dụ tên: nexus-chat).
  2. Lưu toàn bộ mã nguồn này thành file index.html.
  3. Push file index.html lên nhánh main của repository.
  4. Vào Settings > Pages > Tại mục Branch chọn main / /root rồi nhấn Save.
  5. Website của bạn sẽ hoạt động tại link: https://<username>.github.io/nexus-chat/.

Bước 2: Khởi tạo Backend Supabase (Khuyên dùng - Miễn phí)

Tạo dự án mới tại Supabase.com, sau đó chạy đoạn mã SQL dưới đây trong phần SQL Editor của Supabase để tạo bảng dữ liệu:

-- 1. Bảng lưu Users
create table public.profiles (
  id uuid references auth.users not null primary key,
  username text unique not null,
  display_name text,
  avatar_url text,
  status text default 'offline',
  updated_at timestamp with time zone
);

-- 2. Bảng lưu Tin nhắn
create table public.messages (
  id uuid primary key default gen_random_uuid(),
  sender_id uuid references public.profiles(id),
  receiver_id uuid references public.profiles(id),
  content text,
  image_url text,
  created_at timestamp with time zone default timezone('utc'::text, now())
);

-- 3. Bật Realtime cho bảng messages
alter publication supabase_realtime add table messages;
